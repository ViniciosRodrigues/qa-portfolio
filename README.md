# QA Portfolio

## Sobre o projeto

Projeto prático desenvolvido para demonstrar conhecimentos em
Quality Assurance (QA) e testes de software.

O projeto tem como objetivo aplicar na prática conceitos de testes
funcionais, elaboração de casos de teste, execução dos testes,
documentação dos resultados e registro de evidências.

## Objetivo

Praticar e demonstrar conhecimentos relacionados ao processo de
testes de software, desde a elaboração dos casos de teste até a
execução e análise dos resultados.

## Testes realizados

- Testes funcionais
- Testes de login
- Elaboração de casos de teste
- Execução de testes
- Registro de evidências
- Análise dos resultados

## Casos de teste

Os casos de teste estão documentados na pasta `casos-de-teste`.

## Evidências

As evidências das execuções dos testes estão disponíveis na pasta
`evidencias`.

## Ferramentas e conceitos

- QA / Quality Assurance
- Testes funcionais
- Casos de teste
- Evidências de teste
- Git
- GitHub
